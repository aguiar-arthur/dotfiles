# Contributing

These are one person's dotfiles, kept small on purpose. Issues and pull requests are welcome,
and so is forking it as the start of your own setup. Report a security problem privately, as
[SECURITY.md](SECURITY.md) says, not in an issue.

## Making a change

[AGENTS.md](AGENTS.md) has the rules and the steps, for people and AI assistants alike (Claude
Code reads it through `CLAUDE.md`): find the context in its map, read that doc in [docs/](docs),
change the code and its check in `tests/` together, run `tests/nvim.sh`, and say in the pull
request what you could not check (GUI, real language servers, LaTeX).
