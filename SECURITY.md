# Security policy

These are one person's dotfiles, kept small. If you find a problem, such as a leaked secret, an
unsafe step in the `macos/` install scripts, or a workflow that can be abused, report it privately
through [Report a vulnerability](https://github.com/aguiar-arthur/dotfiles/security/advisories/new)
rather than a public issue.

## Disclosure

- I reply within 7 days and fix or decline the report within 30 days.
- Please keep the details private until a fix is on `main`; the fix is credited to you if you
  wish.
- Only the latest commit on `main` is supported.

## Current state

The repository is checked on every push and every Monday; the public score is at
[OpenSSF Scorecard](https://scorecard.dev/viewer/?uri=github.com/aguiar-arthur/dotfiles).
The checks are described in the [security workflow section](docs/tests.md#security-workflow).
